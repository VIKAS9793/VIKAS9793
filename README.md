### AndroJack MCP (open source)

AI coding assistants often write Android code from outdated knowledge: deprecated APIs, wrong patterns, apps that Google Play rejects. AndroJack is a plug-in for AI assistants (built on a standard called [MCP](https://modelcontextprotocol.io)) that gives the assistant live access to official Android documentation and checks the code it writes against 28 rules before you see it.

- 23 tools, available on [npm](https://www.npmjs.com/package/androjack-mcp) and the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=VIKAS9793.androjack-vscode)
- Works with Claude Desktop, Cursor, Windsurf, VS Code Copilot, AWS Kiro, Google Antigravity and JetBrains AI
- Install: `npx -y androjack-mcp@2.0.0 install`

→ [github.com/VIKAS9793/AndroJack-mcp](https://github.com/VIKAS9793/AndroJack-mcp)

### Context Fabric (open source)

AI coding assistants forget your project between sessions, and the notes you keep for them go stale as the code changes. Context Fabric is a plug-in for AI assistants (also built on [MCP](https://modelcontextprotocol.io)) that saves the project's state on every git commit, spots when that saved context no longer matches the code, and hands the assistant a short, up-to-date briefing that fits its token budget.

- Available on [npm](https://www.npmjs.com/package/context-fabric), MIT licensed
- Built around five cooperating engines that watch, check, rank, budget and compose the briefing

→ [github.com/VIKAS9793/context-fabric](https://github.com/VIKAS9793/context-fabric)

### SubscribCHEK (Android app)

Subscriptions are easy to forget and hard to see. SubscribCHEK tracks your recurring subscriptions, shows what they cost over a full year, and guides you through cancelling the ones you no longer want. It never asks for a bank login or an account, has no backend, and keeps everything on your phone.

- Currently in closed testing on Google Play, ahead of its public launch
- Built with Kotlin and Jetpack Compose, for Android

→ [subscribchek.netlify.app](https://subscribchek.netlify.app)

### AsanaPals (Android app)

Most wellness apps turn into one more thing you are failing at: scores, streaks, tasks you missed. AsanaPals is built around companionship instead. Five animal companions keep you company through small moments to move, rest, energize, restart and breathe, with no scores, no streaks and no judgment.

- Works fully offline: the app asks for no internet permission and collects nothing
- Currently in testing ahead of its Google Play launch
- Built with Flutter, for Android

→ [asanapals.space](https://asanapals.space)
