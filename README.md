### [AndroJack MCP](https://github.com/VIKAS9793/AndroJack-mcp)

[![VS Code Installs](https://img.shields.io/visual-studio-marketplace/i/VIKAS9793.androjack-vscode?label=VS%20Code%20Installs&style=flat-square&logo=visual-studio-code&color=007ACC)](https://marketplace.visualstudio.com/items?itemName=VIKAS9793.androjack-vscode) [![npm](https://img.shields.io/npm/dw/androjack-mcp?label=npm%20weekly&style=flat-square&logo=npm&color=CB3837)](https://www.npmjs.com/package/androjack-mcp) [![Website](https://img.shields.io/badge/Website-Live-00D9FF?style=flat-square)](https://androjack-web.netlify.app/)

**530+ downloads in week 1 · VS Code Marketplace · npm · Antigravity IDE Skills**

AI coding assistants generate Android code from stale training data — wrong APIs, deprecated patterns, Play Store rejections. AndroJack intercepts that generation loop and forces live documentation queries before output, then validates every code block against 22 rules before returning it to the developer.

- 22 MCP tools covering Navigation 3, Material 3 Expressive, API 36, KMP, XR, Wear OS, on-device AI
- Level 3 loop-back validation: doc-fetch gate → generation → 22-rule validator → PASS/WARN/FAIL
- Compatible with Claude Desktop, Cursor, Windsurf, Kiro, Antigravity IDE
- 6 rapid updates shipped within 48 hours of launch

`npx androjack-mcp install` · `TypeScript` · `Node.js` · `MCP Protocol`
